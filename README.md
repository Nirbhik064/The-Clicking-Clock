# The-Clicking-Clock-by-Nirbhik.

This is a custom built digital alarm clock made with the help of the guide provided by Hackclub for BLARE.

I made this clock contain a custom PCB, and a custom case for it. I also, made it so that in the future, 
I may be able to connect a 3.7V Li-ion battery into it. That is why, I made a small hole at the base of the pcb to make the underside copper layer visible for easy access. 

It can quite easily just work with the help of a PC's connection.
